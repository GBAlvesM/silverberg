# 🏋️ Silverberg Academia - Sistema de Gestão de Alunos

Aplicação web desenvolvida para cadastro, listagem e remoção de alunos da Silverberg Academia. O projeto foi construído em React integrado a uma API REST em Spring Boot com persistência direta via SQL nativo.

---

## 🛠️ Tecnologias Utilizadas

### Front-end
- **React (com Vite)**
- **JavaScript**
- **CSS Modularizado**
- **Axios** (para consumo da API REST)

### Back-end
- **Java (Spring Boot)**
- **Spring JDBC (`JdbcTemplate`)** — manipulação direta com SQL nativo
- **Banco de Dados Relacional (H2)**

---

## ⚙️ Funcionalidades Implementadas

- [x] **Listagem de Alunos (GET):** busca os registros no banco de dados e exibe na tabela ao montar o componente (`useEffect`).
- [x] **Cadastro de Alunos (POST):** formulário controlado com validações manuais antes do envio.
- [x] **Exclusão de Alunos (DELETE):** remoção direta no banco via ID.
- [x] **Atualização em Tempo Real:** a tabela atualiza instantaneamente após cadastrar ou excluir via *lifting state up* (callbacks), sem recarregar a página.
- [x] **Validações no Front-end:**
  - Nome: preenchimento obrigatório e proibição de dígitos numéricos.
  - E-mail: preenchimento obrigatório com presença de `@` e ponto (`.`).
  - Telefone: preenchimento obrigatório, apenas números.
  - Plano: seleção obrigatória de uma opção válida.

---

## 📖 Documentação da API REST

**Endereço base:** `http://localhost:8080/alunos`

| Método | Endpoint | Descrição 
| :--- | :--- | :--- 
| **GET** | `/alunos` | Retorna a lista de todos os alunos cadastrados
| **POST** | `/alunos` | Cadastra um novo aluno no sistema 
| **DELETE** | `/alunos/{id}` | Remove fisicamente um aluno pelo ID via SQL

## 🔄 Exemplos de Requisições e Respostas

### 1. Listagem de Alunos (`GET /alunos`)
- **Rota:** `GET http://localhost:8080/alunos`
- **Resposta (`200 OK`):**
```json
[
  {
    "id": 1,
    "nome": "Gabriel Miguel",
    "email": "gabriel@email.com",
    "telefone": "11987654321",
    "dataNascimento": "2001-12-04",
    "plano": "Trimestral",
    "situacaoCadastro": true
  }
]
```

### 2. Cadastro de Aluno (`POST /alunos`)
- **Rota:** `POST http://localhost:8080/alunos`
- **Corpo da Requisição (Payload):**
```json
{
  "nome": "Gabriel Miguel",
  "email": "gabriel@email.com",
  "telefone": "11987654321",
  "dataNascimento": "2001-12-04",
  "plano": "Trimestral",
  "situacaoCadastro": true
}
```
- **Resposta de Sucesso (`201 Created` ou `200 OK`):**
```json
{
  "id": 1,
  "nome": "Gabriel Miguel",
  "email": "gabriel@email.com",
  "telefone": "11987654321",
  "dataNascimento": "2001-12-04",
  "plano": "Trimestral",
  "situacaoCadastro": true
}
```

### 3. Exclusão de Aluno (`DELETE /alunos/{id}`)
- **Rota:** `DELETE http://localhost:8080/alunos/1`
- **Resposta de Sucesso (`204 No Content`):**
  - Corpo vazio (*No Content*).
- **Resposta caso o ID não exista (`404 Not Found`):**
  - Corpo vazio ou mensagem de erro padrão.

## 🗄️ Estrutura da Tabela no Banco de Dados

```sql
CREATE TABLE IF NOT EXISTS aluno (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL,
    telefone VARCHAR(20) NOT NULL,
    data_nascimento DATE NOT NULL,
    plano VARCHAR(50) NOT NULL,
    situacao_cadastro BOOLEAN NOT NULL
);
```

## 🚀 Instruções para Executar e Integrar os Projetos

Para o funcionamento completo da aplicação, os dois projetos devem rodar simultaneamente:

### 1. Inicialização do Back-end (Spring Boot)
1. Certifique-se de possuir o Java instalado.
2. Abra o projeto do back-end na IDE de sua preferência (IntelliJ IDEA, Eclipse ou VS Code).
3. Verifique as configurações de conexão no arquivo `src/main/resources/application.properties`.
4. Garanta que o `@CrossOrigin(origins = "*")` esteja presente no `AlunoController` para permitir o acesso vindo do front-end sem bloqueios de CORS.
5. Execute a classe principal da aplicação Spring Boot. O servidor iniciará por padrão em:  
   👉 `http://localhost:8080`

### 2. Inicialização do Front-end (React + Vite)
1. Certifique-se de possuir o Node.js instalado.
2. Abra o terminal na pasta do front-end.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse a URL indicada no terminal (geralmente `http://localhost:5173`).
